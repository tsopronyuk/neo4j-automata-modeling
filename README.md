# 🧮 Graph-Oriented Modeling and Analysis of Finite Automata in Neo4j

[![Neo4j](https://img.shields.io/badge/Neo4j-4.4%2B-blue)](https://neo4j.com/)
[![C++](https://img.shields.io/badge/C%2B%2B-17-blue)](https://isocpp.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This repository contains the source code and reproducibility artifacts associated with the paper *"Graph-Oriented Modeling and Declarative Analysis of Finite Automata Using Property Graphs"*.

The repository implements the mapping of finite automata to **Labeled Property Graphs (LPGs)** in Neo4j and provides Cypher queries for graph-native automata operations, demonstration examples, and a reproducible large-scale benchmark.

## 🧪 Demonstration Automata

`generators/NFAtoNeo4j.cpp` generates the small automata used for demonstrating the graph representation and graph-native automata operations. This generator supports configurations with $\epsilon$-transitions and is intended for reproducible examples rather than for the large-scale benchmark.

Compile with:

```bash
g++ -std=c++17 -O3 generators/NFAtoNeo4j.cpp -o nfa_demo_gen
```

Run:

```bash
./nfa_demo_gen
```

The program generates a Cypher script containing the demonstration automata.

## 📊 Scalability Benchmark

The large-scale benchmark is generated by:

```
generators/100_NFA_table.cpp
```

The benchmark contains five state-space scales:

```
10
100
1000
5000
10000
```

For each scale, **20 independently seeded** pseudorandom NFA instances are generated. Thus, the complete benchmark contains:

$$
5 \times 20 = 100
$$

NFA instances.

### ⚙️ Benchmark Configuration

| Parameter | Value |
|-----------|-------|
| Alphabet $\Sigma$ | $\{a, b\}$ |
| Transition density $\rho$ | $0.25$ |
| Self-loop probability | $0.20$ |
| ε-transitions | ❌ No |
| Bidirectional transitions | ❌ No |
| Accepting states | $\approx 15\%$ of non-initial states |
| Pseudorandom seeds | $1000, \ldots, 1019$ |

Compile with:

```bash
g++ -std=c++17 -O3 generators/100_NFA_table.cpp -o nfa_benchmark
```

Run:

```bash
./nfa_benchmark
```

## 🏗️ Neo4j Setup

The Cypher scripts assume Neo4j 4.4+ or Neo4j 5.x.

### 1️⃣ Initialize the graph schema

```
cypher/automata.cypher
```

### 2️⃣ Create demonstration automata

```
cypher/create_auto_for_demos.cypher
```

### 3️⃣ Run formal operations

```
cypher/formal_operations.cypher
```

### 4️⃣ Load visual styling

In Neo4j Browser, drag and drop `styles/nfa.GRASS` into the query frame to apply semantic color schemes.

## ⚙️ Graph-Native Automata Operations

The demonstration queries cover:

| Operation | Description |
|-----------|-------------|
| ✅ Word acceptance validation | Check if a word is accepted by an automaton |
| 🔍 Bounded shortest word extraction | Find the shortest non-empty accepting path |
| ⊗ Synchronous product construction | $\mathcal{M}_1 \times \mathcal{M}_2$ |
| ∅ Language intersection emptiness | Check if $L(M_1) \cap L(M_2) = \emptyset$ |
| 🎯 Reachability | Determine states reachable from initial state |
| ε-closure | Compute $\varepsilon$-closure of a state |

The graph-analytic procedures based on SCC decomposition, PageRank, and Louvain clustering are used as **complementary structural analyses** rather than as replacements for automata-theoretic algorithms.

## 🔬 Reproducibility

All pseudorandom benchmark seeds are **fixed**. The benchmark generator automatically stores the measurements of every generated instance in `benchmark_results.csv`, allowing the aggregated statistics reported in the paper to be independently reproduced.

### What you can reproduce

| Artifact | How to reproduce |
|----------|------------------|
| 📊 Table with mean $\pm$ std dev | Run `100_NFA_table.cpp` → `results/table_aggregated.tex` |
| 🔄 Raw data for all 100 instances | `results/benchmark_results.csv` |
| 🧪 Demonstration automata | Run `NFAtoNeo4j.cpp` |
| 📈 Figures | Load Cypher data in Neo4j Browser |

> **Principle:** Store the **generator and the data needed to verify the results**, not every redundant intermediate representation.
